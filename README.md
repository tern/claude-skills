# claude-skills

Personal Claude Code skills collection.

## Skills

| Skill | 說明 |
|-------|------|
| [memory-optimizer](./memory-optimizer/) | 自動壓縮 `memory/*.md` 記憶檔，減少 token 用量 |

## 安裝

```bash
npx skills add tern/claude-skills@memory-optimizer
```

或手動複製：

```bash
cp -r memory-optimizer ~/.claude/skills/
```
